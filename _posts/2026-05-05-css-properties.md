# CSS Properties

## Display Property
### Values
- `inline`
- `block`
- `inline-block`
- `none`

```css
h1 {
	display: inline-block;
}
```

## Box Sizing Property
Default value is `content-box`.

### Values
- `content-box`
- `border-box`

```css
h1 {
	box-sizing: border-box;
}
```

## Background Shorthand Property
```css
h1 {
	background: violet;
}
```

## Visibility Property
### Values
- `visible`
- `hidden`

```css
h1 {
	visibility: hidden;
}
```
